# retail-pharmacy-resilience-analysis
A Python-based statistical analysis of retail pharmacy business resilience, exploring external, internal, and customer-related factors using descriptive statistics, bivariate analysis, multicollinearity diagnostics, and ordinal logistic regression.
# Retail Pharmacy Business Resilience Analysis

## Project Overview

This project demonstrates the application of statistical analysis and Python programming to investigate factors associated with retail pharmacy business resilience.

The analysis was conducted as part of a research data analysis project examining the relationship between pharmacy characteristics, operational factors, customer-related factors, and business resilience.

## Research Objectives

The analysis explored six broad areas:

1. External factors associated with retail pharmacy resilience.
2. Internal operational factors associated with resilience.
3. Customer-related factors associated with business resilience.
4. Regulatory and compliance factors.
5. Resilience strategies, customer satisfaction, and value addition.
6. Characteristics of resilient retail pharmacies.
